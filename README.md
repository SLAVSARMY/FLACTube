# YT Music Desktop

Десктопный клиент YouTube Music (оболочка на Electron = встроенный Chromium-браузер) с доп. функциями:

- 🚫 **Без рекламы** — блокировщик на уровне сети (EasyList + uAssets + AdGuard) + встроенный список рекламных URL + автозакрытие промо-диалогов.
- 😴 **Без «Вы ещё слушаете?»** — диалог простоя перехватывается и автоматически нажимается «Продолжить слушать», музыка не прерывается.
- ⤓ **Скачивание в FLAC** — кнопки **FLAC** / **RAW** на панели плеера (или **F9**). FLAC кодируется без потерь из лучшего доступного аудиопотока (как в Spotyflac). RAW — оригинальный поток (m4a/opus) без перекодирования.
- 🎧 **Максимальное качество** — загрузчик берёт потоки в приоритете `258/256/141` (AAC 256–320 kbps, когда YouTube их отдаёт) → `251` (Opus ~160 kbps) → `140`.

## Запуск

Нужен Node.js 18+.

```bash
npm install        # один раз
npm run setup      # один раз: скачает yt-dlp.exe и ffmpeg.exe (~100 МБ) в bin/
npm start
```

Внутри можно войти в свой Google-аккаунт (иконка профиля) — синхронизируются библиотека и плейлисты. Для скачивания вход не нужен.

### Горячие клавиши
| Клавиша | Действие |
|---|---|
| **F9** | Скачать текущий трек в FLAC |
| **F10** | Открыть/показать панель загрузок |
| **F12** | DevTools |

Кнопки **FLAC** / **RAW** висят справа над панелью плеера.

## Сборка портативного .exe

```bash
npm run dist
```
Результат: `dist/YT Music Desktop 1.0.0.exe` (portable, bin/ кладётся внутрь автоматически).

## Честно про качество

- **Стриминг:** без подписки Premium YouTube Music отдаёт ~128–160 kbps (Opus/AAC). Это потолок на стороне сервера — ни один клиент его не обойдёт. Включите «Высокое качество» в настройках самого YT Music (⚙ в приложении).
- **Скачивание:** yt-dlp забирает лучший аудиопоток — до **256 kbps AAC** (itag 141/256, когда YouTube его отдаёт), иначе Opus ~160 kbps.
- **FLAC:** конвертация **без потерь из этого потока** — то есть FLAC не добавляет качества, он просто сохраняет поток без дальнейшей деградации и с обложкой/тегами. Так же работает и Spotyflac для lossy-источников.

## Папка загрузок

По умолчанию `Музыка\YT Music`. Меняется кнопкой «Обзор…» в панели загрузок.

## Если YouTube не открывается (РФ и т.п.)

Панель загрузок (F10) → поле **прокси** → впишите адрес вашего локального VPN/прокси, например:
- `socks5://127.0.0.1:1080` (пользовательские клиенты типа v2rayN/Clash — обычно `10808`/`7890`)
- `http://127.0.0.1:8888`

Прокси применяется и к плееру, и к скачиванию, сохраняется между запусками. Если VPN работает в режиме «всё приложение» (TUN) — ничего вписывать не надо.

## Если что-то не качается

- Проверьте, что в панели загрузок написано «✅ yt-dlp и ffmpeg на месте» (или запустите `npm run setup`).
- Возрастные ограничения: можно передать cookies — добавьте в `lib/downloader.js` аргумент `--cookies-from-browser chrome` (или файл `--cookies cookies.txt`).
- GitHub недоступен/медленно — положите `yt-dlp.exe` и `ffmpeg.exe` в папку `bin/` вручную.

> ⚠ Приложение для личного использования. Скачанные треки не распространяйте — авторские права никто не отменял.

## Плагины (JSON)

Панель загрузок (F10) → ⚙ → **Плагины** → «Папка». Кладёте туда `*.json`-файлы, жмёте «⟳» — плагины применяются без перезапуска. Папка: `%APPDATA%\ytm-desktop\plugins`.

Все поля необязательны, можно комбинировать в одном файле:

```json
{
  "name": "Мой плагин",
  "description": "Что он делает",

  "blockUrls": ["\\/generate_204\\?", "example\\.com\\/tracker"],
  "css": ".твой-селектор { opacity: .5 }",
  "hide": ["ytmusic-mealbar-promo-renderer"],
  "remove": ["#unutcome-banner"],
  "autoDismiss": [
    { "match": "подписаться на Premium", "click": "нет, спасибо" }
  ],
  "js": "api.onTick(() => { /* ваш код, общий тик ~2 раза/сек */ });"
}
```

| Поле | Что делает |
|---|---|
| `blockUrls` | regexp-строки: запросы по ним рвутся на сетевом уровне (дополнение к встроенному блокировщику рекламы). Не регекс — считается подстрокой |
| `css` | стили, вшиваются в страницу |
| `hide` | селекторы → `display:none!important` |
| `remove` | селекторы, узлы удаляются из DOM (переживает перерисовки — чистится в тике) |
| `autoDismiss` | диалог, в тексте которого есть `match`, закрывается кликом по кнопке с текстом `click` |
| `js` | произвольный код на странице (изолированный мир: DOM общий, `require` нет). Получает `api`: `api.toast(msg)`, `api.download('flac'|'copy')`, `api.toggleDrawer()`, `api.ipc` (IPC моста), `api.onTick(fn)`, `api.name` |

Ошибка в одном плагине (битый JSON, исключение в `js`) не роняет остальные — в списке он помечается ⚠. Битый файл ищите в логе (`app.log`).

Пример `js`-плагина — кнопка на странице:

```json
{
  "name": "Кнопка-тест",
  "js": "const b = document.createElement('button'); b.textContent = '⤓'; b.style.cssText = 'position:fixed;left:10px;bottom:120px;z-index:2147483000'; b.onclick = () => api.download('flac'); document.body.append(b);"
}
```
