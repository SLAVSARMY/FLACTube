# FLACTube

Десктопный клиент YouTube Music (оболочка на Electron = встроенный Chromium-браузер) с доп. функциями. Прежнее название — YT Music Desktop: вход в Google-аккаунт, настройки и плагины автоматически переносятся при обновлении.

- 🚫 **Без рекламы** — блокировщик на уровне сети (EasyList + uAssets + AdGuard) + встроенный список рекламных URL + автозакрытие промо-диалогов.
- 😴 **Без «Вы ещё слушаете?» и «Продолжить просмотр?»** — два уровня защиты: приложение каждые 30 с сообщает странице, что пользователь активен (плашка простоя не появляется вовсе, курсор не двигается), а если YouTube всё же покажет диалог — он закрывается автоматически и воспроизведение возобновляется. Работает и в свёрнутом окне.
- ⤓ **Скачивание в FLAC** — кнопки **FLAC** / **RAW** на панели плеера (или **F9**). Трек ищется по ISRC в lossless-источниках (tidal → qobuz → amazon через community-серверы SpotiFLAC, либо свой tidal-api-совместимый сервер в настройках). Нашёлся — скачивается настоящий FLAC (16/24-bit) с тегами и обложкой из Deezer. Не нашёлся — честный оригинальный поток без перекодирования (никаких «FLAC», пережатых из 160 kbps). RAW — оригинальный поток (m4a/opus) как есть.
- 🎧 **Максимальное качество** — загрузчик берёт потоки в приоритете `258/256/141` (AAC 256–320 kbps, когда YouTube их отдаёт) → `251` (Opus ~160 kbps) → `140`.

## Запуск

Нужен Node.js 18+.

```bash
npm install        # один раз
npm run setup      # один раз: скачает yt-dlp.exe и ffmpeg.exe (~100 МБ) в bin/
npm start
```

Внутри можно войти в свой Google-аккаунт (иконка профиля) — синхронизируются библиотека и плейлисты. Для скачивания вход не нужен.

### Горячие клавиши
| Клавиша | Действие |
|---|---|
| **F9** | Скачать текущий трек в FLAC |
| **F10** | Открыть/показать панель загрузок |
| **F12** | DevTools |

Кнопки **FLAC** / **RAW** висят справа над панелью плеера.

## Сборка портативного .exe

```bash
npm run dist
```
Результат: `dist/FLACTube 1.2.0.exe` (portable, bin/ кладётся внутрь автоматически).

Это один .exe (~190 МБ): внутрь упакованы Electron + ffmpeg/yt-dlp. Его можно просто скопировать на **любой компьютер с Windows 10/11 x64** — там не нужен ни Node.js, ни npm. Первый запуск может занять до минуты (само-распаковка во временную папку). SmartScreen может предупредить о неизвестном издателе — exe не подписан сертификатом; жмите «Подробнее → Выполнить в любом случае».

## Честно про качество

- **Стриминг:** без подписки Premium YouTube Music отдаёт ~128–160 kbps (Opus/AAC). Это потолок на стороне сервера — ни один клиент его не обойдёт. Включите «Высокое качество» в настройках самого YT Music (⚙ в приложении).
- **Скачивание:** yt-dlp забирает лучший аудиопоток — до **256 kbps AAC** (itag 141/256, когда YouTube его отдаёт), иначе Opus ~160 kbps.
- **FLAC:** настоящий lossless получается только когда трек нашёлся в lossless-источнике (tidal/qobuz/amazon по ISRC) — тогда это исходный FLAC 16/24-bit без перекодирования. Если трека там нет, приложение **не выдаёт пережатый поток за FLAC** — сохраняет оригинальный кодек (m4a/opus) с тегами и обложкой. Расширение файла всегда честно отражает содержимое.

## Lossless-источники (для настоящего FLAC)

По умолчанию используются community-серверы SpotiFLAC: трек ищется по ISRC (из Deezer) в tidal → qobuz → amazon, качество 24-bit → 16-bit. При первом скачивании может открыться браузер с одноразовой проверкой — пройдите её один раз, сессия сохранится.

Свой сервер: панель загрузок (F10) → ⚙ → поле «lossless-источник» — любой tidal-api-совместимый API (поиск `isrc:...` + выдача потока). Пусто = community-источники.

## Папка загрузок

По умолчанию `Музыка\YT Music`. Меняется кнопкой «Обзор…» в панели загрузок.

## Если YouTube не открывается (РФ и т.п.)

Панель загрузок (F10) → поле **прокси** → впишите адрес вашего локального VPN/прокси, например:
- `socks5://127.0.0.1:1080` (пользовательские клиенты типа v2rayN/Clash — обычно `10808`/`7890`)
- `http://127.0.0.1:8888`

Прокси применяется и к плееру, и к скачиванию, сохраняется между запусками. Если VPN работает в режиме «всё приложение» (TUN) — ничего вписывать не надо.

## Если что-то не качается

- Проверьте, что в панели загрузок написано «✅ yt-dlp и ffmpeg на месте» (или запустите `npm run setup`).
- Возрастные ограничения: можно передать cookies — добавьте в `lib/downloader.js` аргумент `--cookies-from-browser chrome` (или файл `--cookies cookies.txt`).
- GitHub недоступен/медленно — положите `yt-dlp.exe` и `ffmpeg.exe` в папку `bin/` вручную.

> ⚠ Приложение для личного использования. Скачанные треки не распространяйте — авторские права никто не отменял.

## Плагины (JSON)

Панель загрузок (F10) → ⚙ → **Плагины** → «Папка». Кладёте туда `*.json`-файлы, жмёте «⟳» — плагины применяются без перезапуска. Папка: `%APPDATA%\ytm-desktop\plugins`.

Все поля необязательны, можно комбинировать в одном файле:

```json
{
  "name": "Мой плагин",
  "description": "Что он делает",

  "blockUrls": ["\\/generate_204\\?", "example\\.com\\/tracker"],
  "css": ".твой-селектор { opacity: .5 }",
  "hide": ["ytmusic-mealbar-promo-renderer"],
  "remove": ["#unutcome-banner"],
  "autoDismiss": [
    { "match": "подписаться на Premium", "click": "нет, спасибо" }
  ],
  "js": "api.onTick(() => { /* ваш код, общий тик ~2 раза/сек */ });"
}
```

| Поле | Что делает |
|---|---|
| `blockUrls` | regexp-строки: запросы по ним рвутся на сетевом уровне (дополнение к встроенному блокировщику рекламы). Не регекс — считается подстрокой |
| `css` | стили, вшиваются в страницу |
| `hide` | селекторы → `display:none!important` |
| `remove` | селекторы, узлы удаляются из DOM (переживает перерисовки — чистится в тике) |
| `autoDismiss` | диалог, в тексте которого есть `match`, закрывается кликом по кнопке с текстом `click` |
| `js` | произвольный код на странице (изолированный мир: DOM общий, `require` нет). Получает `api`: `api.toast(msg)`, `api.download('flac'|'copy')`, `api.toggleDrawer()`, `api.ipc` (IPC моста), `api.onTick(fn)`, `api.name` |

Ошибка в одном плагине (битый JSON, исключение в `js`) не роняет остальные — в списке он помечается ⚠. Битый файл ищите в логе (`app.log`).

Пример `js`-плагина — кнопка на странице:

```json
{
  "name": "Кнопка-тест",
  "js": "const b = document.createElement('button'); b.textContent = '⤓'; b.style.cssText = 'position:fixed;left:10px;bottom:120px;z-index:2147483000'; b.onclick = () => api.download('flac'); document.body.append(b);"
}
```

## История изменений

### v1.2.0
- **Ребрендинг: FLACTube** (бывший YT Music Desktop) — новое имя, новая иконка. Все данные (вход в Google, lossless-сессия, конфиг, плагины) автоматически переносятся со старой папки — повторный вход не нужен.

### v1.1.0
- **Анти-простой в корне:** приложение каждые 30 с сообщает странице об активности пользователя — плашка «Video paused. Continue watching?» / «Продолжить просмотр?» больше не появляется вовсе (курсор не двигается, работает в свёрнутом окне). Автоклик по диалогу остался запасным слоем, теперь понимает и новый текст плашки (EN/RU).
- **Починена сборка настоящего FLAC:** из-за неверного порядка аргументов ffmpeg ветка true-lossless не работала вовсе (ошибка «Error opening input files»); у m4a из-за этого же терялась обложка.
- **Отказоустойчивость lossless-источников:** перебор tidal → qobuz → amazon (24 → 16 bit); отказ одного источника (401/кулдаун/сеть) больше не отменяет загрузку — пробуется следующий. Отмена только если недоступно всё.
- Тесты конвейера: `scripts/test-flac.js` (реальная сеть), `scripts/test-flac-lossless.js` (имитация lossless-сервера), `scripts/test-community.js`, `scripts/test-sources.js`.

### v1.0.0
- Первый релиз: Electron-клиент YouTube Music, блокировщик рекламы, автопропуск «Вы ещё слушаете?», скачивание FLAC/RAW, прокси, JSON-плагины, портативный .exe.
